# Nexus 6LAYER Blueprint Pack

This repository is a materialized architecture and execution pack for Nexus. It is not a lightweight product brief. It defines a deterministic 45-node implementation graph, locked names and contracts, required components, self-hosted defaults, provider fallbacks, verification gates, live-fire outcomes, deployment profiles, and operating rules for coding agents.

Read in this order:

1. PREFLIGHT.md
2. AGENTS.md
3. PROJECT_BRIEF.md
4. NEXUS_ARCHITECTURE_ATLAS.md
5. ARCHITECTURE.md
6. COMPONENT_REGISTRY.yaml
7. VERSIONS.lock.yaml
8. .agent/GRAPH.md
9. .agent/LOOPS.md
10. .agent/prompts/run-graph.md

The implementation authority is the graph, not ROADMAP.md. Production deployment is not authorized by this pack. The final graph node produces a signed, tested, deployable release and an exact manual promotion command.
