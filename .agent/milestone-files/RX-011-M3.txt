AUD-068: installRelease now binds the request to the validated release manifest: opts.releaseId must equal manifest.release_id, every supplied component must be declared by the manifest, and every supplied declaredDigest must equal the manifest's digest for that component. Staged bytes are validated against these manifest-bound digests, so injected/undeclared payloads and mismatched digests are denied with MANIFEST_INVALID before any mutation. Hostile proofs: unbound digest, extra undeclared component, release-id mismatch all fail closed.
