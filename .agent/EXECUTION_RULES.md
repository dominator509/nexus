1. Read AGENTS.md and run the full boot sequence.
2. Work one leased node only.
3. Implement from the active ExecPlan, never ROADMAP.md.
4. Continue by default; stop only for the explicit STOP list.
5. Re-ground before each milestone.
6. Change only declared paths.
7. Verify every symbol and external claim; invent nothing.
8. Use only COMMANDS.md.
9. Follow the bounded ladder and never repeat a fix.
10. Do not weaken, skip, ignore, or mask a gate.
11. Production paths contain no mocks, stubs, demo behavior, sample success, or placeholders.
12. Optional providers remain unavailable until certified with real dependencies.
13. Commit every milestone and append ledger evidence.
14. A node is done only with milestone evidence, node verify, expected files, NODE_DONE, and green tag.
15. Final reports state observed facts, remaining certifications, and ship status.
