# INCIDENT RESPONSE

- [ ] Create an incident with severity, affected resources, and correlation IDs.
- [ ] Preserve logs, traces, audit, event, and deployment evidence.
- [ ] Contain through deterministic policy-approved actions.
- [ ] Diagnose using documented commands and avoid destructive speculation.
- [ ] Remediate through the governed engineering loop.
- [ ] Verify, communicate, close, and create regression coverage.
