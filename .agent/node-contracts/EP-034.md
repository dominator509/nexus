# EP-034 NODE CONTRACT

Purpose: Implement Flutter iOS and Android apps, passkeys, biometrics, voice, push, Bluetooth, approvals, remote controls, and secure local storage.

## Public interfaces
- MobileSession
- VoiceRemote
- ApprovalPrompt
- DeviceEnrollment
- BluetoothDiscovery
- SecureStore
- PushInbox
- RemoteControl

## Acceptance obligations
- iOS and Android share Flutter UI and use native modules for passkeys, biometrics, Bluetooth, secure stores, push, and background audio
- High-risk approvals bind to device and user
- Offline low-risk controls follow cached policy
- Accessibility and large text remain functional

## Required specs
- .agent/specs/.agent/specs/SPEC-017-web-desktop-ios-android-device-security-and-remote-control.md

## Replacement and fallback
Disable unsupported background features per platform while preserving foreground chat, voice, push, and approvals.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
