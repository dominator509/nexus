# EP-033 NODE CONTRACT

Purpose: Implement accessible React PWA, cloud dashboard, chat, operations center, approvals, settings, security console, and Tauri desktop.

## Public interfaces
- DashboardShell
- ChatWorkspace
- ObjectiveView
- ApprovalCenter
- FleetView
- SecurityConsole
- ProviderSettings
- AuditExplorer

## Acceptance obligations
- Web dashboard supports chat when phone use is impossible
- PWA and Tauri share contracts without duplicating business logic
- Core flows meet WCAG 2.2 AA checks
- Realtime state, approvals, task graph, incidents, and settings are coherent

## Required specs
- .agent/specs/.agent/specs/SPEC-004-user-experience-dashboard-desktop-and-onboarding.md
- .agent/specs/.agent/specs/SPEC-017-web-desktop-ios-android-device-security-and-remote-control.md

## Replacement and fallback
Ship responsive PWA first; Tauri remains a thin signed wrapper in the same node.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
