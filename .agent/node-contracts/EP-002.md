## Acceptance obligations
- All IDs are typed and non-interchangeable in Rust
- JSON Schema validation and generated Rust, TypeScript, Python, and Dart models agree
- Vocabulary tables reject unknown risk, privacy, route, principal, and capability classes
- No provider brand leaks into canonical domain names

## Replacement and fallback
Generate only Rust and JSON Schema first, then generate other languages from the same schemas in this node before closure.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
