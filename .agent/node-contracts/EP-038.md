# EP-038 NODE CONTRACT

Purpose: Implement OpenTelemetry, GlitchTip, metrics, logs, traces, dashboards, alerts, SLOs, fleet health, and incident operations.

## Public interfaces
- TelemetryContext
- RedactionPolicy
- MetricCatalog
- TracePolicy
- HealthAggregator
- IncidentSink
- FleetHealth
- SloEvaluator

## Acceptance obligations
- OpenTelemetry is the instrumentation standard
- GlitchTip receives errors and incidents without secrets
- Logs, metrics, traces, audit, and events correlate
- Dashboards and alerts answer health, failures, agent work, cost, cache, and security

## Required specs
- .agent/specs/.agent/specs/SPEC-007-observability-incident-correlation-and-operations.md

## Replacement and fallback
Use local structured logs and Prometheus metrics when external collectors are unavailable.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
