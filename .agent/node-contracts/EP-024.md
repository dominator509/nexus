# EP-024 NODE CONTRACT

Purpose: Implement Sonos, TV, media, lighting, HVAC, vacuum, irrigation, appliance, vehicle, and future robot provider contracts.

## Public interfaces
- MediaProvider
- ApplianceProvider
- IrrigationProvider
- VacuumProvider
- RobotProvider
- DeviceCapabilityMapper
- DeviceCommandVerifier

## Acceptance obligations
- Home Assistant is preferred for commodity devices
- Direct providers exist only for capability or reliability gaps
- Commands are target-scoped and verified
- Future robots receive no broader authority than declared capabilities

## Required specs
- .agent/specs/.agent/specs/SPEC-011-home-devices-media-appliances-irrigation-and-robotics-providers.md

## Replacement and fallback
Expose Home Assistant-backed capabilities only and mark direct integrations unavailable.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
