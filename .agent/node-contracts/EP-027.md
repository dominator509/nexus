# EP-027 NODE CONTRACT

Purpose: Implement ICTFax, HylaFAX compatibility, fax documents, inbound routing, outbound status, T.38 or carrier fallback, and audit.

## Public interfaces
- FaxProvider
- IctFaxProvider
- HylaFaxProvider
- CloudFaxProvider
- FaxJob
- FaxDocument
- FaxStatus
- InboundFaxRoute

## Acceptance obligations
- ICTFax is the primary self-hosted control sidecar
- HylaFAX is a compatibility backend
- Cloud carrier fallback uses the same FaxProvider contract
- Outbound and inbound documents, status, retries, routing, and audit are real

## Required specs
- .agent/specs/.agent/specs/SPEC-014-email-phone-fax-notifications-and-communications-routing.md

## Replacement and fallback
Use HylaFAX with a certified modem or SIP path if ICTFax packaging cannot pass the selected deployment profile.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
