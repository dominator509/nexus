# EP-039 NODE CONTRACT

Purpose: Implement license policy, sidecar boundaries, SBOM, provenance, signed artifacts, image scanning, dependency policy, and advisory monitoring.

## Public interfaces
- LicenseClassifier
- ComponentBoundary
- SbomGenerator
- ArtifactSigner
- ProvenanceAttestation
- AdvisoryMonitor
- DependencyWaiver

## Acceptance obligations
- Every shipped component has license, source, version, digest, integration mode, and notices
- Copyleft sidecars remain process-separated and compliant
- OCI images and packages carry SBOM and provenance
- Critical advisories fail release unless a time-bounded ADR documents mitigation

## Required specs
- .agent/specs/.agent/specs/SPEC-019-licensing-sbom-provenance-and-supply-chain-security.md

## Replacement and fallback
Remove or replace a component whose license or security posture cannot pass review.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
