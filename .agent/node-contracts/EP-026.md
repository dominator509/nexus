# EP-026 NODE CONTRACT

Purpose: Implement universal mailboxes, Gmail, Microsoft Graph, IMAP and SMTP, self-hosted mail option, attachments, drafts, sends, and audit.

## Public interfaces
- EmailProvider
- Mailbox
- Thread
- Message
- Attachment
- Draft
- SendRequest
- MailChangeFeed
- MailPolicy

## Acceptance obligations
- Gmail, Microsoft Graph, and generic IMAP or SMTP map to canonical objects
- Read and send scopes are separate
- Attachments use ArtifactStore and malware scanning
- Draft, approval, send, reply, forward, archive, and label actions audit correctly

## Required specs
- .agent/specs/.agent/specs/SPEC-014-email-phone-fax-notifications-and-communications-routing.md

## Replacement and fallback
Use generic IMAP and SMTP plus controlled polling when provider webhooks are unavailable.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
