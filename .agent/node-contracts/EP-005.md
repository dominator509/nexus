# EP-005 NODE CONTRACT

Purpose: Implement NATS JetStream, canonical events, outbox, replay, correlation, and durable consumers.

## Public interfaces
- EventPublisher
- EventConsumer
- OutboxRepository
- InboxRepository
- StreamProvisioner
- EventEnvelope
- ConsumerCheckpoint

## Acceptance obligations
- Database mutation and outbox insert are atomic
- JetStream publish acknowledgement precedes outbox completion
- Consumers deduplicate and resume after restart
- Correlation and causation survive publish, replay, and projection

## Required specs

## Replacement and fallback
Use one canonical stream and subject namespace before introducing stream sharding.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
