# EP-025 NODE CONTRACT

Purpose: Implement Asterisk LTS, SIP provider abstraction, bidirectional media, governed call workflows, STT and TTS, disclosure, and transcripts.

## Public interfaces
- TelephonyProvider
- AsteriskProvider
- SipCarrierProvider
- CallSession
- MediaBridge
- CallPolicy
- DisclosurePolicy
- TranscriptArtifact

## Acceptance obligations
- Asterisk exchanges bidirectional audio with Nexus voice sessions
- Carrier credentials remain isolated
- Dial, answer, hangup, transfer, DTMF, hold, and status are governed capabilities
- Recording and AI disclosure follow policy and jurisdiction configuration

## Required specs
- .agent/specs/.agent/specs/SPEC-014-email-phone-fax-notifications-and-communications-routing.md

## Replacement and fallback
Support outbound operator-supervised calls before autonomous conversational calls.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
