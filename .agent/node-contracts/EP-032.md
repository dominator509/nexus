# EP-032 NODE CONTRACT

Purpose: Implement person-aware push, desktop, speaker, SMS, email, phone, watch, car, privacy, urgency, quiet hours, and escalation routing.

## Public interfaces
- NotificationRouter
- NotificationEnvelope
- ChannelProvider
- DeliveryPolicy
- PrivacyRouting
- EscalationPolicy
- DeliveryReceipt

## Acceptance obligations
- Person, urgency, privacy, presence, availability, quiet hours, and acknowledgement determine delivery
- Sensitive shared-room responses route privately
- Failures escalate across configured channels without duplication
- Every delivery has a receipt and correlation

## Required specs
- .agent/specs/.agent/specs/SPEC-014-email-phone-fax-notifications-and-communications-routing.md

## Replacement and fallback
Use mobile push plus dashboard inbox as the minimum reliable channel pair.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
