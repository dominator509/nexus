# EP-000 NODE CONTRACT

Purpose: Discovery, source verification, toolchain lock, license baseline, and truthful command surface.

## Public interfaces
- VerifiedSourceRecord with URL, authoritative owner, version, release date, license, checksum or digest, retrieval date, and decision status
- ToolchainLock with exact versions and a containerized development fallback
- ComponentDecision with self-hosted default, replacement contract, license mode, security posture, and source evidence

## Acceptance obligations
- Every locked version and source has authoritative evidence
- Every selected component has a commercial integration mode and replacement boundary
- The development toolchain can be reproduced without an unpinned latest reference
- Every command in COMMANDS.md has a truthful implementation or is owned by a later node

## Required specs
- .agent/specs/.agent/specs/SPEC-000-product-scope-and-constitutional-priorities.md
- .agent/specs/.agent/specs/SPEC-019-licensing-sbom-provenance-and-supply-chain-security.md

## Replacement and fallback
Use the pinned devcontainer as the canonical toolchain when the host cannot install a locked compiler or SDK.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
