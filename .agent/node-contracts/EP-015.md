# EP-015 NODE CONTRACT

Purpose: Implement the Nexus Model Router Contract, policy routing, RouteLLM-compatible scoring, escalation, and Microbrain interface.

## Public interfaces
- NexusModelRouter
- RoutingFeatures
- RoutingDecision
- RoutePolicy
- LearnedRouterAdapter
- MicrobrainProvider
- EscalationPolicy

## Acceptance obligations
- Routing considers domain, complexity, risk, privacy, locality, latency, cost, availability, and historical success
- RouteLLM and LLMRouter are replaceable strategies
- The policy engine can override learned routing for security
- Microbrain uses the same ReflexProvider contract and can remain disabled

## Required specs
- .agent/specs/.agent/specs/SPEC-009-reflex-ai-model-gateway-routing-cache-and-microbrain-seam.md
- .agent/specs/.agent/specs/SPEC-025-microbrain-dataset-training-evaluation-shadow-and-promotion.md

## Replacement and fallback
Use deterministic weighted policy routing until a learned router beats it on the frozen routing benchmark.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
