- Setup profiles hardware and recommends local versus API providers
- One-time QR enrollment establishes certificates and private mesh
- Failures are resumable, explainable, and never leave insecure partial state

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
