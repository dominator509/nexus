# EP-006 NODE CONTRACT

Purpose: Implement Temporal namespaces, workers, workflow contracts, approvals, retries, signals, and cancellation.

## Public interfaces
- ObjectiveWorkflow
- ApprovalWorkflow
- ConnectorCertificationWorkflow
- IncidentRemediationWorkflow
- DeploymentWorkflow
- WorkflowSignal
- WorkflowQuery

## Acceptance obligations
- Workers resume after restart without duplicating side effects
- Human approvals can wait for days and use immutable assertions
- Cancellation and timeout semantics are explicit
- Activities use idempotency keys and bounded retries

## Required specs
- .agent/specs/.agent/specs/SPEC-023-events-outbox-temporal-workflows-scheduling-and-human-approvals.md

## Replacement and fallback
Use one Temporal namespace and one worker process with task queues separated by capability.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
