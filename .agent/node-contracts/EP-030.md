# EP-030 NODE CONTRACT

Purpose: Implement OPNsense and OpenWrt adapters, AdGuard Home, inventory, segmentation, baselines, anomaly scoring, and quarantine proposals.

## Public interfaces
- FirewallProvider
- DnsSecurityProvider
- NetworkInventory
- DeviceFingerprint
- BehaviorBaseline
- NetworkFinding
- QuarantineProposal

## Acceptance obligations
- OPNsense and OpenWrt share a canonical network provider
- AdGuard Home supplies DNS security and telemetry
- IoT, trusted, guest, camera, and quarantine segments are modeled
- Core Sentinel is light enough for a normal home and can propose verified containment

## Required specs
- .agent/specs/.agent/specs/SPEC-013-sentinel-firewall-dns-network-detection-and-endpoint-security.md

## Replacement and fallback
Operate in observe-only mode on unsupported routers while retaining DNS and endpoint signals.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
