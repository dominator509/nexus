# EP-016 NODE CONTRACT

Purpose: Implement hybrid retrieval, context capsules, memory consolidation, retention, privacy, and graph-aware context construction.

## Public interfaces
- ContextEngine
- ContextCapsule
- HybridRetriever
- MemoryConsolidator
- MemoryProposal
- PrivacyFilter
- GraphExpansionPolicy

## Acceptance obligations
- Context is purpose-limited and permission-filtered
- Exact, full-text, vector, graph, recency, and importance signals are combined
- Agents cannot write canonical memory directly
- Private shared-room requests use private response routing

## Required specs
- .agent/specs/.agent/specs/SPEC-002-data-memory-fabric-search-and-world-graph.md

## Replacement and fallback
Disable semantic consolidation and use deterministic retrieval if model-assisted consolidation fails evaluation.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
