# EP-011 NODE CONTRACT

Purpose: Build Rust, Python, and TypeScript connector SDKs plus a sandboxed legacy Connector Sidecar.

## Public interfaces
- RustConnectorSdk
- TypeScriptConnectorSdk
- PythonConnectorSdk
- SidecarAdapter
- LegacyPoller
- WebhookNormalizer
- CredentialBroker

## Acceptance obligations
- All SDKs pass one shared contract corpus
- Sidecars wrap REST, SOAP, SQL, CLI, filesystem, and browser-last-resort sources without direct authority
- Commands are idempotent and events are versioned
- Credentials remain in the broker rather than connector prompts

## Required specs
- .agent/specs/.agent/specs/SPEC-022-universal-connector-contract-sdks-sidecar-and-legacy-integration.md

## Replacement and fallback
Ship Rust SDK and protocol conformance first, then make TypeScript and Python thin generated bindings within this node.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
