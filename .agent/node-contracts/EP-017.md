# EP-017 NODE CONTRACT

Purpose: Implement objectives, task graph, agent registry, A2A adapters, Codex, Claude Code, Hermes, OpenClaw, budgets, and artifacts.

## Public interfaces
- AgentRegistry
- AgentAdapter
- AgentTask
- CapabilityRequest
- AgentArtifact
- AgentBudget
- CodexAdapter
- ClaudeCodeAdapter
- HermesAdapter
- OpenClawAdapter

## Acceptance obligations
- Agents request capabilities rather than named peers
- Nexus remains the parent orchestrator and canonical task owner
- Codex, Claude Code, Hermes, and OpenClaw can start, stream, pause, cancel, resume, and return artifacts where their harness supports it
- Repository workers use isolated worktrees and scoped tools

## Required specs
- .agent/specs/.agent/specs/SPEC-010-objectives-agents-harness-adapters-artifacts-and-skills.md

## Replacement and fallback
Use process and CLI adapters when a harness lacks native A2A support, preserving the canonical task contract.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
