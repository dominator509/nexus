# EP-007 NODE CONTRACT

Purpose: Deploy Keycloak and implement OIDC, passkeys, service identities, sessions, device enrollment, and step-up.

## Public interfaces
- OidcClient
- TokenValidator
- PasskeyEnrollment
- DeviceEnrollment
- SessionService
- StepUpChallenge
- RecoveryKit

## Acceptance obligations
- Owner onboarding creates passkey and offline recovery material
- Tokens validate issuer, audience, signature, time, scopes, and device context
- Sessions revoke and audit correctly
- High-risk operations require configured step-up strength

## Required specs
- .agent/specs/.agent/specs/SPEC-005-authentication-authorization-secrets-trust-and-multi-user-privacy.md

## Replacement and fallback
Use Keycloak local accounts and passkeys before enabling external identity federation.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
