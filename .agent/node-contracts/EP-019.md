# EP-019 NODE CONTRACT

Purpose: Implement incident correlation, diagnosis, patching, independent review, HITL approval, canary, verification, and rollback.

## Public interfaces
- IncidentEngine
- DiagnosisTask
- PatchProposal
- ReviewVerdict
- CanaryPlan
- RollbackPlan
- RemediationApproval
- IncidentMemory

## Acceptance obligations
- Crashes and agent failures become grouped incidents
- Diagnosis and patching run in isolated environments
- Production deployment always requires policy and human approval at defined risk levels
- Canary regression automatically rolls back and preserves evidence

## Required specs
- .agent/specs/.agent/specs/SPEC-018-self-healing-engineering-and-incident-feedback-loop.md

## Replacement and fallback
Create diagnosis and patch artifacts without automatic deployment when a safe canary cannot be built.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
