# EP-037 NODE CONTRACT

Purpose: Implement ArtifactStore with local, NAS, SeaweedFS, MinIO compatibility, R2, B2, and S3 plus encrypted backup, restore, and migration.

## Public interfaces
- ArtifactStore
- ArtifactMetadata
- ArtifactVersion
- ArtifactHash
- StorageMigration
- BackupSet
- RestorePlan
- RetentionClass

## Acceptance obligations
- Local filesystem, NAS, SeaweedFS, R2, B2, S3, and MinIO compatibility use one contract
- Artifacts are content-addressed and versioned
- Backups encrypt before leaving the node
- Restore and backend migration verify hashes before deletion

## Required specs
- .agent/specs/.agent/specs/SPEC-024-artifacts-object-storage-backup-restore-and-disaster-recovery.md

## Replacement and fallback
Use local encrypted filesystem storage and restic-compatible backup before enabling scalable object storage.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
