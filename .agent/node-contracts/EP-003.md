# EP-003 NODE CONTRACT

Purpose: Implement people, households, businesses, devices, sessions, presence evidence, and tenant boundaries.

## Public interfaces
- Principal
- PrincipalType
- PersonProfile
- Household
- BusinessBinding
- DeviceIdentity
- PresenceEvidence
- IdentityConfidence
- InteractionContext
- PrivacyContext

## Acceptance obligations
- People, households, businesses, devices, and sessions remain independently scoped
- Voice, room, BLE, mobile, and camera evidence combine without becoming cryptographic authentication
- Unknown and guest users receive bounded local permissions
- Cross-tenant and cross-business reads fail without existence disclosure

## Required specs
- .agent/specs/SPEC-001-core-domain-identity-references-and-world-model.md
- .agent/specs/SPEC-005-authentication-authorization-secrets-trust-and-multi-user-privacy.md

## Replacement and fallback
Use account plus device identity without probabilistic presence fusion until every evidence provider is available.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
