# EP-018 NODE CONTRACT

Purpose: Implement signed Agent Skills packages, trust levels, permissions, evals, promotion, composition, and versioning.

## Public interfaces
- SkillRegistry
- SkillPackage
- SkillManifest
- SkillSignature
- SkillTrustLevel
- SkillEvaluator
- SkillComposer
- SkillProposal

## Acceptance obligations
- Agent Skills format is portable and Nexus metadata governs permissions
- Skills are signed, immutable by version, and scan before install
- Skills cannot grant themselves tools or secrets
- Factory output must pass evals and human promotion

## Required specs
- .agent/specs/.agent/specs/SPEC-010-objectives-agents-harness-adapters-artifacts-and-skills.md

## Replacement and fallback
Allow built-in and locally generated skills only; disable community installation.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
