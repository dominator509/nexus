# EP-036 NODE CONTRACT

Purpose: Implement node registry, workload placement, OpenTofu modules, cloud-init, Contabo, Hetzner, DigitalOcean, AWS, generic SSH, and private mesh.

## Public interfaces
- ComputeNode
- PlacementConstraint
- PlacementDecision
- CloudProvider
- ProvisioningPlan
- BootstrapBundle
- FleetEnrollment

## Acceptance obligations
- Workloads declare resources, locality, trust, latency, and availability
- OpenTofu modules provision supported providers reproducibly
- Cloud-init establishes only bootstrap identity and pulls signed releases
- Fully local and existing SSH remain first-class paths

## Required specs
- .agent/specs/.agent/specs/SPEC-016-deployment-profiles-setup-compute-fabric-provisioning-and-updates.md

## Replacement and fallback
Use generic existing-SSH provisioning when a cloud API adapter fails certification.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof.
