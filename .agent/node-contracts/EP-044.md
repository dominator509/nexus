# EP-044 NODE CONTRACT

Purpose: Implement the Nexus Control Plane Runtime - a real runnable control-plane server binary under `apps/control-plane/`, the application composition root, `infra/compose/core.yaml`, canonical runtime configuration, canonical base URL/domain resolution, `/healthz`, `/readyz`, `/v1/capabilities`, graceful startup/shutdown, runtime smoke ownership, local deterministic runtime bring-up, and runtime observability bootstrap.

## Public interfaces
- ControlPlaneConfig
- RuntimeHealth
- RuntimeReadiness
- CapabilityList
- ControlPlaneServer
- RuntimeLifecycle
- RuntimeSmoke

## Acceptance obligations
- A real runnable control-plane server binary exists under `apps/control-plane/` (no placeholder, mock, or demo mode)
- GET /healthz returns `{"status":"healthy"}` with HTTP 200 when the runtime is healthy
- GET /readyz returns `{"ready":true}` with HTTP 200 when the runtime is ready
- GET /v1/capabilities returns `{"capabilities":[...]}` with HTTP 200 and a non-empty list
- `infra/compose/core.yaml` exists and brings up the control plane deterministically for the local profile
- Canonical base URL/domain resolution: the runtime serves the address configured through `NEXUS_BASE_DOMAIN` / `NEXUS_SMOKE_URL` conventions
- Graceful startup and shutdown: the server binds, serves, and stops on signal without leaking processes
- Runtime smoke ownership: `scripts/smoke/runtime.sh` is the single canonical runtime smoke, and the smoke gate activates only at `at-least EP-044`
- Local deterministic runtime bring-up: `sh scripts/local-start.sh core` works against `infra/compose/core.yaml`
- Runtime observability bootstrap: telemetry context is initialized at startup; health/readiness expose typed states

## Replacement and fallback
Run the control-plane server directly from the built binary when the compose stack is unavailable; the binary itself is the source of truth for health, readiness, and capability discovery.

## Reality rule
An interface is not operational merely because its type or adapter compiles. It must pass the owning node tests and any listed live-fire or certification proof. The runtime smoke must be run against the real server and return the canonical sentinels.
