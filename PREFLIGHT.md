# PREFLIGHT

## Covenant

This file is the only planned interactive checkpoint before the implementation graph begins. The operator obtains every REQUIRED item, chooses every required one-of provider group, fills `.env`, and runs `sh scripts/preflight.sh` until the output contains `preflight: ok`. Optional integrations remain disabled and must not be advertised as certified until their provider live-fire proof passes.

## Release profiles

- `core`: self-hosted control plane, identity, policy, memory, events, workflows, dashboard, installer, and DeepSeek reflex provider.
- `home`: core plus Home Assistant, voice, Frigate, and local device control.
- `communications`: core plus email, Asterisk, SIP carrier, and fax.
- `business`: core plus Hydra and Social Command Center.
- `sentinel`: core plus OPNsense or OpenWrt and AdGuard Home.
- `full`: every profile plus every required provider certification.

## Required one-of groups by profile

### Production infrastructure

Choose one for BYOC, or select `existing-ssh` or `fully-local`:

- Contabo: `CONTABO_CLIENT_ID`, `CONTABO_CLIENT_SECRET`, `CONTABO_API_USER`, `CONTABO_API_PASSWORD`.
- Hetzner: `HETZNER_API_TOKEN` with server, network, firewall, image, and SSH-key rights.
- DigitalOcean: `DIGITALOCEAN_TOKEN` with Droplet, VPC, firewall, project, volume, and SSH-key rights.
- AWS: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION` with the exact least-privilege policy generated by EP-036.
- Existing SSH: `NEXUS_EXISTING_HOST`, `NEXUS_EXISTING_SSH_USER`, `NEXUS_EXISTING_SSH_KEY_FILE`.
- Fully local: `NEXUS_LOCAL_TARGET=1`.

### PSTN calling and external fax

Asterisk and ICTFax are self-hosted, but public telephone and fax delivery require a carrier. Choose one:

- Telnyx: `TELNYX_API_KEY`, `TELNYX_SIP_USERNAME`, `TELNYX_SIP_PASSWORD`, `TELNYX_FROM_NUMBER`.
- Twilio: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_SIP_DOMAIN`, `TWILIO_FROM_NUMBER`.

Phaxio is an optional fax fallback: `PHAXIO_API_KEY`, `PHAXIO_API_SECRET`.

### Real email provider certification

Choose at least one for the full communications profile:

- Gmail: `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`, test mailbox and refresh token obtained by the setup wizard.
- Microsoft: `MICROSOFT_TENANT_ID`, `MICROSOFT_CLIENT_ID`, `MICROSOFT_CLIENT_SECRET`, test mailbox.
- Generic mail: `IMAP_URL`, `SMTP_URL`, `MAIL_TEST_RECIPIENT`.
- Self-hosted mail: local Stalwart profile and a controlled test domain.

### Network and home hardware certification

- Home Assistant: `HOME_ASSISTANT_URL`, `HOME_ASSISTANT_TOKEN`.
- OPNsense: `OPNSENSE_URL`, `OPNSENSE_API_KEY`, `OPNSENSE_API_SECRET`.
- OpenWrt: `OPENWRT_URL`, `OPENWRT_USERNAME`, `OPENWRT_PASSWORD`.
- Roku Home: `ROKU_HOME_TEST_DEVICE_INVENTORY` and operator-owned test hardware. No direct local API is assumed.

## Hardware lab inventory

Provider certification uses real owned devices. Record serial/model identifiers in `hardware/LAB_INVENTORY.yaml` before the owning node starts. The minimum full-profile lab is one Home Assistant edge, one controllable light, one contact sensor, one Voice Preview or ESPHome satellite, one Bluetooth headset, one Frigate-compatible camera, one Roku Home camera, one OPNsense or OpenWrt test firewall, one Android device, and one iOS device.
